Nova CRM 1.3 — نسخه PWA برای iPhone و Android

این نسخه از کد رابط کاربری آخرین پروژه NovaCRM ساخته شده و روی همان پروژه Supabase کار می‌کند. نصب به صورت وب‌اپ (PWA) است، نه فایل IPA یا اپ App Store.

انتشار:
1) تمام محتویات این پوشه را روی هاست استاتیک HTTPS منتشر کنید؛ فایل index.html باید در ریشه دامنه باشد.
2) در Supabase → Authentication → URL Configuration مقدار Site URL را روی دامنه نهایی بگذارید و مسیرهای Redirect لازم را اضافه کنید. برای دعوت کارمند، مسیر /activation/ را نیز اضافه کنید.
3) در Edge Function Secrets مقدار NOVA_ACTIVATION_URL را روی https://YOUR-DOMAIN/activation/ بگذارید.
4) تنظیمات config.js را فقط با URL و publishable key پروژه خود بررسی کنید؛ هیچ service_role/secret key در مرورگر قرار ندهید.
5) برای iPhone، سایت را با Safari باز کنید → Share → Add to Home Screen → Add.

تغییر دسترسی کارمند:
- کارمند می‌تواند پرونده مشتری جدید ثبت کند و فقط پرونده‌هایی را می‌بیند که خودش ایجاد کرده است.
- کارمند اجازه ویرایش، حذف، ثبت پرداخت و خروجی‌گرفتن ندارد؛ این عملیات در رابط فعلی برای مدیر باقی مانده است.
- سیاست دیتابیس باید migration شماره 202611100001_nova_user_data_isolation.sql را داشته باشد. این migration دسترسی را بر اساس created_by و auth.uid() محدود می‌کند و برای کارمند هم INSERT روی پرونده خودش را مجاز می‌کند.
- اگر این migration قبلاً روی پروژه اجرا شده، دوباره اجرا نکنید. اگر اجرا نشده، قبل از استفاده عملیاتی از Supabase SQL Editor و پس از بکاپ اجرا شود. هیچ داده‌ای در این بسته حذف یا منتقل نمی‌شود.

آزمایش پیشنهادی:
با یک حساب کارمند، یک مشتری آزمایشی ثبت کنید؛ سپس با همان کارمند صفحه را تازه‌سازی کنید و بررسی کنید پرونده خودش نمایش داده شود. با حساب کارمند نباید پرونده‌های سایر کارکنان دیده شوند.

Service Worker فقط فایل‌های ثابت را cache می‌کند؛ ورود و عملیات پایگاه داده به اینترنت نیاز دارند.
